SentinelTrade UI Architecture & Design Plan1. Core ConceptA unified single-page application (SPA) that defaults to a High-Conviction Monitoring Dashboard. Access to the Admin Infrastructure Panel is gated by user groups, allowing seamless switching without re-authentication.2. Main Dashboard (The "Sentinel" View)The default landing page for all users. Focused on high-level data and trade logic.A. Visual LayoutHero Metric: Total Portfolio Value & 24h Delta (Alpaca API).The "Thesis" Feed: A real-time scrolling vertical log of S1-CEREBRO’s thoughts (e.g., "Analyzing NVDA: Sentiment 0.8 based on earnings rumors...").Active Sentinels Card: Status indicators for S0, S1, and S2 (Green/Yellow/Red pulse).Current Positions: A clean table showing open trades, cost basis, and current profit/loss.B. Functional ComponentsManual Approval Modal: A pop-up that appears when a high-risk trade is pending. It shows the "Buy/Sell" button alongside the AI's reasoning.Timeframe Selector: Switch between Day, Week, and Month views for the performance chart.3. Admin Panel (The "Command" View)Visible only to users in the admin group. Accessible via a "Switch to Admin" button in the sidebar.A. Visual LayoutInfrastructure Health: Real-time CPU/RAM/IO graphs for the Dell R540 nodes.Nginx Proxy Manager Integration: An iframe or API-driven table showing active proxies and SSL statuses.Node Power Control: Buttons to trigger rc-service restarts or container reboots.B. Functional ComponentsTailscale Status Bridge: A diagnostic view showing if the tunnel is active and which "Serve" names are broadcasted.Log Streamer: A terminal-style view that can switch between npm-admin logs and grafana logs.4. Navigation & Authentication LogicSingle Sign-On (SSO): Handled via Tailscale Auth or a centralized JWT.Role-Based UI (RBUI):group: user -> Sees Sidebar with: [Dashboard, Performance, Settings].group: admin -> Sees Sidebar with: [Dashboard, Performance, Infrastructure, Logs, Settings].View Switcher: A toggle at the bottom of the sidebar: "Switch to System Admin" which changes the layout and color scheme (e.g., from a professional Blue to a "System Dark" Slate).5. Technical Implementation (React)State Management: Use a global UserContext to track isAdmin status.Routing: Use conditional rendering:{isAdmin && <AdminRoute path="/admin" component={InfrastructurePage} />}
Theming: Distinct CSS variables for "Sentinel Mode" (Clean/Light) vs "Admin Mode" (Terminal/Dark).
