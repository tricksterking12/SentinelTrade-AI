B. Paste it into the S0-BEACON Terminal:Run these commands inside the S0-BEACON shell:mkdir -p ~/.ssh
chmod 700 ~/.ssh
echo "PASTE_YOUR_PUBLIC_KEY_STRING_HERE" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
3. Fix "Connection Timed Out" (Alpine SSH Config)By default, Alpine SSH often restricts root login or isn't listening correctly. Run these inside the S0-BEACON shell:# 1. Install and Enable SSH
apk add openssh
rc-update add sshd default

# 2. Allow Root Login & Ensure Port 22 is open
sed -i 's/#PermitRootLogin.*/PermitRootLogin yes/' /etc/ssh/sshd_config
sed -i 's/#Port 22/Port 22/' /etc/ssh/sshd_config

# 3. Restart the service
rc-service sshd restart
4. Verify the ConnectionTry this from Windows again:ssh -i C:\Users\james\.ssh\sentinel_beacon root@172.16.2.82
